# Samet Zengin

**Forward Deployed Engineer** in Istanbul · [sametzengin.dev](https://sametzengin.dev)

I work where a product meets the systems a business already runs on. Most of what I build connects things that were never designed to talk to each other: ERP modules, payment flows, webhooks moving between platforms, and the queues and retries that keep all of it standing when one side goes quiet.

Since 2022 I have run my own practice, [Luumtech](https://luumtech.com), working with clients in Turkey, Germany, the Netherlands and Switzerland, and I have shipped remotely for teams in the Netherlands and Australia. The work is usually half engineering and half conversation.

### Selected work

- **[Rugroom](https://sametzengin.dev/blog/building-rugroom)**: place a rug inside a photo of your own room, in real time. Python image analysis, Three.js geometry and a browser renderer that has to respect every table leg. [Try the live scene](https://sametzengin.dev/rugroom).
- **[KUMSAN Şile production optimization](https://sametzengin.dev/thesis)**: an ILP recipe optimizer and demand forecasting dashboard for a silica sand facility, built with Python, Flask and PuLP.
- **ERP modules, payment flows and Shopify integrations**: custom modules, Stripe and Revolut pipelines, Shopify apps with OAuth installs, billing and webhooks.
- **Huawei**: winner of the HMS Competition and the HSD Design Competition, and a developer relations internship running HMS SDK workshops.
